How to Use BL Automation App

Standard

Create BL (All in One Processing)

  1. Set Vessel Details: Fill in the Vessel Name, Voyage (VOY), Port of Loading (POL), Port of Discharge (POD), Estimated Time of Departure (ETD), and check the NAVIS option if applicable.
  2. Select Source Files: Choose the target IV files for the vessel.
  3. Execute Processing: Click Create BL to start the automated workflow.
  4. Output Destination: Generated files will be saved in BLC ALL MACRO/WIP BL/ and its subfolders (FOR RPA, BL, and BL OUTPUT).
Macro Driven

Create BL Per Macro Automation

  1. Stage 1 (Shipping List): Select IV files to generate and save the Shipping List.
  2. Stage 2 (Separate Units): Select the folder containing the IV files to separate Single and Multi-unit files.
  3. Stage 3 (RPA Setup): Select the FOR RPA folder.
  4. Stage 4 (BL Copy): Select the FOR RPA folder.
  5. Stage 5 (Checker & Table): Select the BL/ALL folder to generate and save the Checker Result and IV Table.
  6. Stage 6 (BL Formatting): Select the BL/ALL folder.
  7. Stage 7 (Attach Sheet): Select the FOR RPA/MULTI folder to transfer the ATCH (2) sheet into matching BL files.
  8. Stage 8 (Finalize BL): Select the BL/ALL folder to finalize all documents.
  9. Output Destination: All output files will be structured inside BLC ALL MACRO/WIP BL/ across the FOR RPA, BL, and BL OUTPUT subfolders.
